# Sinaliza+ — evolução técnica

## Situação da versão TCC
- Interface e navegação: funcionais.
- Cadastro/login do protótipo: armazenamento local.
- Sessão de intérprete/admin: persiste até desconectar.
- Conteúdo administrativo: demonstração local.

## Próximo estágio
- PHP + MySQL em `backend/` e `database/`.
- Perfis profissionais com foto, certificação e modalidade.
- Conteúdo com fonte, URL, data e status de publicação.
- Solicitação de intérprete.
- Recuperação de senha por e-mail no servidor.
- Moderação e auditoria.

## Regra importante
O localStorage é adequado apenas para a demonstração offline/protótipo. Dados reais de usuários devem ficar no servidor.
